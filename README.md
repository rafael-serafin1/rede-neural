# rede-neural

Esse é o código de uma rede neural capaz de aprender portas lógicas e prever suas saídas com precisão. O código foi feito tomando como inspiração o vídeo do programador e youtuber Nicolai Nielsen, cuja proposta é uma rede neural em C capaz de aprender apenas a porta lógica XOR. Dito isso, eu expandi a ideia para as outras portas disponíveis e acrescentei a orientação a objetos, já que estou usando C++.

Link do vídeo: [Nicolai Nielsen Neural Network from Scratch in C](https://www.youtube.com/watch?v=LA4I3cWkp1E&t=3235s)
